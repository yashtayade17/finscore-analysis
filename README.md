# FinScore Analysis

A web-based financial score analysis tool built with HTML.

🔗 **Live demo:** https://finscore-analysis.vercel.app

## Features
- Enter your financial details and get a score
- Simple, clean, responsive interface
- Runs fully in the browser, no installation needed

## Tech Stack
- HTML, CSS, JavaScript
- Deployed on Vercel

## How to Run Locally
1. Download or clone this repository
2. Open `index.html` in your browser
